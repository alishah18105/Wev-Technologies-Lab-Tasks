# Lab 3 – HTML Forms

## 📌 Overview

This lab focuses on creating and working with **HTML forms**. The objective was to learn how forms are structured and how different form elements can be used to collect information from users.

## 🎯 Objectives

* Understand the structure of an HTML form
* Learn how to create forms using HTML
* Work with different form input elements
* Understand how user information can be collected through forms
* Practice organizing form fields using HTML

## 📝 What I Created

For this lab, I created a webpage containing an HTML form with different input fields and form controls.

The lab demonstrates the use of:

* Text input fields
* Form labels
* Radio buttons
* Checkboxes
* Dropdown/select menus
* Text areas
* Submit and other form buttons
