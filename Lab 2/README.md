# Lab 2 – Adding Audio and Video to a Webpage

## 📌 Overview

This lab focuses on adding **multimedia content** to a webpage using HTML. The main objective was to learn how to embed and display **audio and video** directly within a web page.

The webpage was structured using HTML and styled using CSS, with multimedia files organized inside the project assets.

## 🎯 Objectives

* Learn how to embed audio in a webpage
* Learn how to embed video in a webpage
* Understand HTML multimedia elements
* Organize media files using project assets
* Apply CSS styling to the webpage
* Understand how HTML and CSS work together to create a complete webpage

## 📝 What I Created

For this lab, I created a webpage that demonstrates:

* 🎵 Embedding and playing an audio file
* 🎥 Embedding and playing a video file
* 📄 Structuring the webpage using HTML
* 🎨 Styling the webpage using CSS
* 📁 Managing multimedia files through an `assets` folder

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

### HTML Concepts Practiced

* `<audio>`
* `<video>`
* `<source>`
* HTML page structure
