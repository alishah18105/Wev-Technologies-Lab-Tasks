# Lab 4 – Styling HTML Forms with CSS

## 📌 Overview

This lab focuses on **styling the HTML form created in Lab 3 using CSS**. The objective was to learn how CSS can be used to improve the appearance, layout, and overall presentation of an HTML form.

## 🎯 Objectives

* Apply CSS styling to an existing HTML form
* Improve the visual appearance of form elements
* Understand CSS selectors and properties
* Style input fields, labels, buttons, and other form elements
* Practice separating HTML structure from CSS styling

## 📝 What I Created

In this lab, I took the **HTML form created in Lab 3** and enhanced its design using CSS.

The implementation includes styling for:

* Form layout and spacing
* Labels and input fields
* Text areas
* Selection controls
* Buttons
* Overall form appearance

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📚 What I Learned

Through this lab, I learned how to use CSS to transform a basic HTML form into a more visually organized and user-friendly interface. I also practiced connecting an external CSS stylesheet to an HTML document and applying different styles to individual form elements.

This lab built upon the form creation concepts learned in **Lab 3** and introduced the importance of separating **content and structure (HTML)** from **presentation and styling (CSS)**.
