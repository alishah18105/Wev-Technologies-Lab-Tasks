# 🌐 Web Technologies Lab Tasks

This repository contains the **Web Technologies lab tasks** completed as part of my university coursework. It documents my practical learning and hands-on experience with different web development technologies through a series of lab exercises and assignments.

## 🛠️ Tech Stack

The labs in this repository cover the following technologies:

* **HTML** – Structure and content of web pages
* **CSS** – Styling and layouts
* **JavaScript** – Interactivity and client-side functionality
* **Bootstrap** – Responsive design and UI components
* **React.js** – Component-based frontend development
* **Vite** – Frontend development and build tool
* **Node.js** – Backend JavaScript runtime
* **Express.js** – Backend and REST API development
* **PostgreSQL** – Database management and data storage
* **XML** – Data representation and structured data

## 🎯 Purpose

The purpose of this repository is to document my practical work throughout the **Web Technologies course** and demonstrate my understanding of frontend, backend, database, and web development concepts.
