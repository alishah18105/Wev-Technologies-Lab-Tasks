# Lab 1 – Introduction to HTML

## 📌 Overview

This lab introduces the fundamentals of **HTML** by creating a simple informational webpage about **Artificial Intelligence (AI)**.

The webpage demonstrates the use of basic HTML elements to structure and present content, including headings, paragraphs, images, hyperlinks, horizontal lines, and lists.

## 🎯 Objectives

* Understand the basic structure of an HTML document
* Learn how to use common HTML elements
* Create and organize content using headings and paragraphs
* Add images and hyperlinks to a webpage
* Create unordered lists
* Structure a simple informational webpage

## 📝 What I Created

For this lab, I created a webpage titled **"Artificial Intelligence (AI)"** containing:

* Introduction to Artificial Intelligence
* Explanation of why AI is important
* Applications of AI
